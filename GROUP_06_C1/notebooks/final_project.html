def wilson(k, n, z=1.96):
    p = k / n
    c = (p + z**2 / (2 * n)) / (1 + z**2 / n)
    h = z * np.sqrt(p * (1 - p) / n + z**2 / (4 * n**2)) / (1 + z**2 / n)
    return c - h, c + h

def race_rho(d, x="grid", y="final_pos", min_n=8):
    """Spearman rho between x and y inside each race (needs >= min_n drivers): one value per race."""
    return d.dropna(subset=[x, y]).groupby("raceId")[[x, y]].apply(
        lambda g: stats.spearmanr(g[x], g[y])[0] if len(g) >= min_n else np.nan).rename("rho")

def partial_spearman(x, y, z):
    r = np.corrcoef([stats.rankdata(x), stats.rankdata(y), stats.rankdata(z)])
    return (r[0, 1] - r[0, 2] * r[1, 2]) / np.sqrt((1 - r[0, 2]**2) * (1 - r[1, 2]**2))

def holm(p):
    p = np.asarray(p); m = len(p); order = np.argsort(p); adj = np.empty(m); run = 0
    for k, i in enumerate(order):
        run = max(run, (m - k) * p[i]); adj[i] = min(1, run)
    return adj

1. Choosing the question: why not pit-stop times¶

The first candidate line was pit-stop efficiency. The recorded duration is the whole time in the pit lane (entry to exit), so it depends on the length of each circuit's pit lane, not only on the crew. We measure how much of its variation the circuit explains (stops of 60 s or less, i.e. without red-flag stoppages, 2014–2024).

The starting position and the finishing position, on the other hand, are observed directly for every driver. We therefore study starting position → result.

3. Measuring the relationship¶

3.1 IDC: how closely the finishing order follows the grid¶

For each race we compute the Spearman rank correlation between grid slot and finishing position among the finishers (+1 = same order as the grid, 0 = no relation, −1 = reversed order). The IDC is the median over races. Its 95 % interval resamples whole races (5,000 bootstrap samples).

3.3 Association, not effect: holding team strength fixed¶

A fast car tends to qualify well and to finish well, so part of the grid–result agreement goes with the car. The partial correlation measures the grid–result association among drivers whose teams had the same championship rank before the race (a coarse proxy for car strength). Intervals resample whole races (1,000 samples).

In [7]:

Observation. The association drops from 0.77 to 0.50 but stays clearly positive. This is consistent with car strength acting on both the grid and the result; it does not measure the car's effect, nor the effect of the grid (driver skill, reliability and penalties are not held fixed, and nothing was assigned at random). Note that 0.77 (pooled over all finishers) and 0.81 (IDC, median of per-race values) are different measures.

5. Predicting who scores points¶

Question. Before the start, will this driver finish in the points (top 10)? One row = one driver in one race. Positive class = finishes 1st–10th (exactly 10 per race, about 49 % of rows).

Prediction moment (T1). The grid is published and the race has not started. Only four inputs exist then: grid slot (a pit-lane start is placed behind the last slot), pit-lane flag, the team's championship rank after the previous round, and the qualifying gap to the fastest qualifier. Anything observed during or after the race is excluded.

Model and reference. A logistic regression (standardised inputs, median imputation, L2 with C = 1, threshold 0.5), compared with the grid rule: "the top 10 on the grid score points".

Season-by-season (walk-forward) evaluation. Each season is predicted by a model trained on all earlier seasons only, so every prediction looks one season ahead, as a strategist would. Seasons 2018–2022 are the validation seasons, where the choices were checked; 2023–2024 are the test seasons, evaluated once with the specification frozen. Whole seasons are used, so no race is ever split between training and prediction.

at["grid_filled"] = at["grid"].fillna(at["starters_in_race"])
at["pitlane"] = at["pitlane_start"].astype(int)
FEATURES = ["grid_filled", "pitlane", "constructor_rank_prev", "quali_gap_pct"]
TARGET = "top10"
AFTER_START = ["pos_lap1", "gained_lap1", "race_pace_gap_pct", "fastest_lap_rank", "final_pos", "position",
               "positions_gained", "finished", "classified", "status", "points", "laps", "circuit_races"]
assert not set(FEATURES) & set(AFTER_START + [TARGET])           # no information from during or after the race

def make_model():
    prep = ColumnTransformer([("num", Pipeline([("impute", SimpleImputer(strategy="median")),
                                                ("scale", StandardScaler())]), FEATURES)])
    return Pipeline([("prep", prep), ("logit", LogisticRegression(C=1.0, max_iter=1000))])

def scores(y, yhat):
    return {"accuracy": accuracy_score(y, yhat), "precision": precision_score(y, yhat),
            "recall": recall_score(y, yhat), "F1": f1_score(y, yhat)}

PRED, plan, models = [], [], {}
for season in range(2018, 2025):
    train, target = at[at["year"] < season], at[at["year"] == season]
    assert train["date"].max() < target["date"].min() and set(train["raceId"]).isdisjoint(target["raceId"])
    m = make_model().fit(train[FEATURES], train[TARGET]); models[season] = m
    p = m.predict_proba(target[FEATURES])[:, 1]
    PRED.append(target[["raceId", "driverId", "year", "grid", "team_tier", "finished", TARGET]].assign(
        p=p, model=(p >= 0.5).astype(int), reference=(target["grid"] <= 10).astype(int)))
    plan.append({"predicted season": season, "trained on": f"2014–{season - 1}", "training rows": len(train),
                 "role": "validation" if season <= 2022 else "test",
                 "regulation period": "2022 rules" if season >= 2022 else "2014–2021 rules"})

Observation. On the test seasons the model makes fewer errors of both kinds than the grid rule, so precision, recall and F1 all improve. The gain is small and uncertain: the race-bootstrap interval of the F1 difference includes zero. By season, the model is clearly ahead in 2023 and slightly behind in 2024. This matches the IDC: 2023 was the season where the finishing order followed the grid least (IDC 0.72), so the grid rule was weakest; in 2024 the order followed the grid closely (IDC 0.86) and the grid rule was hard to beat.

Why accuracy alone is not enough. About half of the drivers score, so two rules with similar accuracy can make very different mistakes. A false positive (points expected, none scored) leads a team to plan a race around points that do not come; a false negative (a scorer missed) leads it to undervalue a car that could fight for points.

def clean(o):
    if isinstance(o, dict): return {str(k): clean(v) for k, v in o.items()}

    if isinstance(o, (np.floating,)): return float(o)
